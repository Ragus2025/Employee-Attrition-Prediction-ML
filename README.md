# Employee Attrition Prediction (Machine Learning)

## 📌 Project Overview
This project builds a machine learning model to predict employee attrition (who will leave the company). The goal is to help HR teams reduce turnover and improve employee retention.

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 🤖 ML Models Used
- Logistic Regression
- Random Forest Classifier

## 📊 Steps Performed
- Data cleaning & preprocessing  
- Handling missing values  
- Label encoding & feature scaling  
- Model training & evaluation  
- Accuracy, precision, recall calculation  
- Feature importance visualization  

## 🎯 Outcome
Achieved ~84% accuracy and identified top factors influencing attrition.
